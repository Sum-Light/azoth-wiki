## 对白与流程

对白保留原文；场景标题、说话人和编排说明为人工整理。说话人无法确认时保留“拟定”或“待核”标注。玩家名与动态文本以占位符保留；未解码字形不猜写。互斥回复不是一次事件里连续发生的对白。

本轮补入皮丘最初托付、钢铁与黑曜森林后续、冰壁前后、洗翠连续篇、七夜调查结果、海之神线索、球迷朝圣、Cos大会等场景。补齐场景与原分场合并展示，原文与第一人称见闻录分别保留。无法可靠保存进度的连续演出并入完成回顾，显隐Flag、周期遭遇、共用变量不冒充持久历史；独立线索与可选后日谈各用自身标记。

## 奖励与反向获取

- 实物与点数以发放指令为依据，覆盖宝可梦、蛋、携带物、道具数量、金钱与 BracerPoints。道具及宝可梦按内部 ID 对应图鉴页面，避免同名形态混淆。
- Mega 波动按任务对白与源码解锁标记补充，独立列为奖励，并关联普通形态与 Mega 形态。波动代表超级进化权限，不代表赠送宝可梦，也不计入赠送物种数。仅有源码定义的巨钳螳螂波动保留“游戏内触发待核”。
- 招式教学、极限特训、觉醒力量属性服务、服装与电话登记等也可反查；每项保留确认依据和开放条件。教学关联对应招式页；王冠、心之鳞片等服务费用不算赠礼。
- 完成奖励、接取物品、待交付物品、后续赠送、购买及退款分开标注。临时队伍不算永久奖励，退款不算净收益。
- 首次选择、随机分支、答题点数等互斥奖励按条件分别列出，不将多个分支相加。部分支路还有文字限制，须同时阅读任务页的奖励说明。
- “未确认”不等于奖励为零；当对白提示与指令结果不同，保留差异说明。源码定义尚未验证触发的奖励也保留注明。
- 反查覆盖本批支线相关获取途径，并非全游戏物品与宝可梦来源全集。技能机器保留当前 ROM 编号。
- 本次补充收录 8 种波动与 16 项其他解锁。源码中另有“失控超级进化”等事件，尚未对应本批任务，不混入任务022“制服狂暴宝可梦”。

## 地点与地图

每个分场附地点与触发入口说明，任务页包含可放大的地图和入口编号。图像直接使用 Map_event_editor 的地图渲染逻辑导出。地图已按修订台本重新导出，地点页增加任务与场景反向链接；最新清单见[支线涉及地图](maps.md)。

- 根据地图人物、调查、踩格及地图头脚本到台本对白的可达关系定位；共用菜单、通用发奖文字不单独作为定位依据。
- 坐标为从0开始的地图格坐标，表示事件初始位置；移动后的位置可能不同。地图头脚本没有固定触发格，不补造坐标。
- 入口与对白可达不等于全部分支已在游戏内验证，仍须结合任务前置条件与阶段阅读。
- 任务表导航可能指向占位地图，单独放在“任务导航参考与地点依据”中，不据此认定剧情地点。
- 新增追踪 `var8004 → 支线分发表 → 当前源码` 的跳转，补上此前漏掉的地图关联。尚无实际脚本入口证据的分场继续标明地点待核，不以导航地图代替。
- 地图名称沿用当前ROM区域名，室内地图或剧情专用地图可能保留旧名；地图编号和导出图片一并保留，避免凭对白擅自改名。

## 维护

页面由 `wiki/tools/generate_sidequests.py` 生成，修订台本、游戏详情与阶段条件一同保存在 `wiki/data/sidequests.json`，经核对的波动和功能解锁另存于 `wiki/data/sidequest_unlocks.json`。普通构建直接读取这些快照；各任务末尾可展开查看奖励依据。

地点快照另存于 `wiki/data/sidequest_locations.json`，图片位于 `wiki/docs/sidequests/maps/`；由完整工作区的 `tools/export_sidequest_locations.py` 导出。普通构建同时合并地点快照，并检查任务号与分场标题一致。

重新生成图鉴后会自动恢复任务反查。完整工作区刷新顺序为：`generate_sidequests.py --refresh-review --snapshot-only`，再运行 `tools/export_sidequest_locations.py`，然后运行Wiki生成器及MkDocs构建。地图读取 `任务/BPRE0.gba` 与当前CFRU事件源码；导出快照保存实际ROM摘要。独立Wiki构建无需ROM。
