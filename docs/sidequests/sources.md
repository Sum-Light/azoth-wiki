# 支线任务资料说明

[返回任务目录](index.md) · [奖励反查](rewards.md)

## 收录范围

本页收录经人工编排的 96 项支线任务，连续编号为**任务001–任务096**。任务001为“皮丘的旅途”，任务096为“被解开的封印”。原任务表中两项未实装任务不收录。皮丘章节的长者身份已确认为岩铁。

资料来自 2026年10月3日 的 CFRU 源码、ROM 事件指令与任务表提取快照，并沿用奖励版 Word 台本的人工分场。快照日期不代表游戏版本号，也不表示所有流程都已经过游戏内触发测试。

## 对白与流程

对白保留原文；场景标题、说话人和编排说明为人工整理。说话人无法确认时保留“拟定”或“待核”标注。玩家名与动态文本以占位符保留；未解码字形不猜写。互斥回复不是一次事件里连续发生的对白。

部分长任务的中间场景仍有缺口。详情页呈现确认选入台本的对白，未确认归属的附近文本保留在原始报告的《关联对白与待核对》中，不当作已确认任务流程发布。

## 奖励与反向获取

- 以发放指令为依据，覆盖宝可梦、蛋、携带物、道具数量、金钱与 BracerPoints。道具及宝可梦按内部 ID 对应图鉴页面，避免同名形态混淆。
- 完成奖励、接取物品、待交付物品、后续赠送、购买及退款分开标注。临时队伍不算永久奖励，退款不算净收益。
- 首次选择、随机分支、答题点数等互斥奖励按条件分别列出，不将多个分支相加。部分支路还有文字限制，须同时阅读任务页的奖励说明。
- “未确认”不等于奖励为零；当对白提示与指令结果不同，保留差异说明。源码定义尚未验证触发的奖励也保留注明。
- 反查覆盖本批支线相关获取途径，并非全游戏物品与宝可梦来源全集。技能机器保留当前 ROM 编号。

## 维护

页面由 `wiki/tools/generate_sidequests.py` 生成，结构化数据为 `wiki/data/sidequests.json`。源码与人工编排的校验摘要保存在数据文件中。各任务末尾可展开查看奖励指令的地址或符号。

重新生成图鉴后会自动恢复任务反查。更新人工编排或奖励核对后，使用 `--refresh-source` 同步本地台本资料，再构建 wiki。
