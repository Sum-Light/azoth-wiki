# 宝可梦水银 HOME

支持水银 FC 的 25 箱存档，以及当前版本的 18 箱存档。HOME 仍使用原有数据和备份格式，两个版本之间传送时自动按已有映射转换。

- 选择一只宝可梦后点击目标格，或拖拽移动／交换，最后点击“保存 HOME 和 SAV”。
- 当前版本独有的宝可梦／形态、携带道具、招式不能进入 HOME；只要一项不兼容，整只拒绝传送，不会卸下道具或删除招式。
- 旧格式无法保留的昵称、薄荷、极限训练、特性槽、闪光修正等会明确提示并禁止传送。部分相遇地点跨版本后记为未知地点。
- 原 HOME 备份与 PMH1 二维码／密钥继续可用；不兼容的新版本个体也不能通过分享绕过检查。

本地存档盒子管理工具：读取 GBA 存档（128 KiB Flash Save）↔ 本地 HOME 盒子互转，支持导出备份、扫码/密钥分享单只宝可梦。
