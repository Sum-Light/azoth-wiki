!!! tip "数据安全"
    HOME 数据保存在浏览器 localStorage 中。清除"网站数据"、换浏览器或换电脑前，请先在应用内点**导出备份**。

## 在手机上找存档

先在游戏内保存并退出游戏，再打开 HOME。选择的是 **128 KiB 的游戏存档**（SAV 等），不是 ROM，也不是模拟器的即时存档。

### Android：授权目录，搜索并覆盖

1. 使用支持本地文件读写的浏览器（例如 Chrome 132+），选择 Pizza Boy、My Boy 或其他模拟器。
2. 可先输入 ROM 名称，例如「宝可梦水银.gba」，再点击 **选择存档文件夹**。选完后 HOME 自动搜索这个目录及其子目录；名称可只填部分，也可留空。
3. 只有一份匹配存档，或多份结果中只有一份与 ROM 同名时，会直接读取并收起搜索面板。多份同名存档仍需核对路径与修改时间后点击读取；不会按最新时间擅自选择。
4. 修改 ROM 名后点击搜索，也可自动读取唯一匹配。当前有未保存编辑或目录未能完整搜索时，只列出结果。完成编辑后点 **保存 HOME 并覆盖原 SAV**，按系统提示授予写入权限。
5. 回到模拟器，从游戏标题画面读取存档。不要恢复修改前的即时存档。

HOME 会尝试记住各模拟器的目录；下次点击搜索时，浏览器可能要求重新授权。只有从可写文件句柄读取的文件才能覆盖；普通文件导入和目录副本会明确显示“导出 SAV”。

My Boy 旧版常见位置是内部存储的 MyBoy/save；新版及 Pizza Boy 请以模拟器设置中的存档位置为准。Android 11+ 通常不允许系统选择器访问 Android/data、Android/obb 等目录。若模拟器支持自定义存档目录，可改到 Documents 下的共享文件夹；否则使用模拟器的存档导出／导入功能。**覆盖导出的副本不会自动更新模拟器内部存档。**

### iPhone / iPad：Delta 导出与导入

1. 在 Delta 游戏列表长按游戏，在 **Manage Save File / 管理存档文件** 中导出存档到“文件”。
2. 在 HOME 选择导出的 SAV，编辑后点 **保存 HOME 并导出 SAV**，通过系统分享或保存链接存到“文件”。
3. 回到 Delta 同一菜单，选择 **Import File / 导入文件**，导入编辑后的 SAV。

iOS Safari 目前无法向网页授予原文件写入权限。iOS 18.4+ 可尝试选择目录搜索副本，但仍需导出和导入。Delta 内部文件名可能与 ROM 名不同，找不到时清空搜索词或直接选导出的文件。HOME 导出时保留原文件名，系统可能自动添加编号；同名下载不代表已经覆盖。

## 覆盖前备份与冲突

每次直接覆盖前，HOME 会在当前浏览器保留最近一组原 SAV 与配套 HOME 备份，可分别下载。备份保存失败、写入授权被拒绝或原文件已被模拟器修改时，会停止覆盖并保留当前编辑。请在重新读取之前导出当前 SAV 副本；恢复备份时，SAV 和 HOME 应配套使用。

本地备份只保留最近一组，清除网站数据会丢失，不替代自行下载备份。网页无法阻止模拟器在保存期间同时写文件，请编辑前先退出游戏。系统分享、下载或导入是否最终完成需要玩家确认。
