# 宝可梦水银 HOME

支持水银 FC 的 25 箱存档，以及新版对战塔的 18 箱存档。HOME 仍使用原有数据和备份格式，两个版本之间传送时自动按已有映射转换。

- 选择一只宝可梦后点击目标格，或拖拽移动／交换，最后点击“保存 HOME 和 SAV”。
- 网页游玩：先在游戏内保存并关闭游戏页，再用同一浏览器打开 HOME，选择 FC 1.33 或对战塔 3.0，点“读取网页存档”，整理后点“保存到浏览器”。重新打开游戏后从游戏内继续，勿读取旧即时存档。
- 新版对战塔独有的宝可梦／形态、携带道具、招式不能进入 HOME；只要一项不兼容，整只拒绝传送，不会卸下道具或删除招式。
- 特性槽或闪光修正需要兼容时，会重新计算 PID，保留特性槽、性格、性别和闪光状态；传回新版后使用转换后的 PID。需要转换的个体标为“转换”，点击可查看详情。
- 奇异球会变为普通精灵球，传回后仍为精灵球。传送和分享前都会显示这项调整。
- 无法保留的昵称、薄荷、极限训练等仍禁止传送；不能安全保留斑纹、特殊形态或进化分支时也会拦截。部分相遇地点跨版本后记为未知地点。
- 原 HOME 备份与 PMH1 二维码／密钥继续可用；不兼容的新版本个体也不能通过分享绕过检查。

本地存档盒子管理工具：读取 GBA 存档（128 KiB Flash Save）↔ 本地 HOME 盒子互转，支持导出备份、扫码/密钥分享单只宝可梦。
